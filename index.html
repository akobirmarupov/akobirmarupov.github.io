Men Akobir Marupov, backend dasturchiman. Asosiy ishim — Python va Django yordamida haqiqiy foydalanuvchilar ishlatadigan tizimlarning ichki qismini qurish.

O‘quvchi test ishlaydi, xatolari ustida takrorlash kartochkalari orqali ishlaydi, XP va streak yig‘adi, haftalik ligalarda boshqalar bilan raqobatlashadi.   • 9 ta Django ilovasi, 17 000+ qator Python kodi, shundan 3 000+ qatori testlar.

  • Google va Apple orqali kirish, JWT token rotatsiyasi va blacklist.
  • Obuna va to‘lov mantig‘i: tarif chegaralari, kunlik limitlar, tarifni oshirish qoidalari.
  • Celery Beat bilan fon ishlari — reyting qayta hisoblash, ligalarni yopish, obunani tugatish.
  • Kontent uch tilda (uz / ru / en), til so‘rovdan aniqlanadi.
  • Har push’da GitHub Actions testlarni, migratsiyalarni va API sxemasini tekshiradi.
